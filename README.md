### 🚀 Projeto aplicado

**Projeto de Banco de Dados — Produção Têxtil**

Desenvolvimento de um banco de dados relacional em PostgreSQL para representar etapas e registros de uma operação industrial têxtil. O projeto reúne modelagem, integridade dos dados, carga de dados sintéticos e consultas analíticas.

* Modelagem com 15 tabelas relacionadas
* Definição de chaves primárias, estrangeiras e restrições de integridade
* Carga de dados sintéticos para simular ordens, lotes, máquinas, operadores, produção, qualidade e paradas
* 12 consultas analíticas para investigar volumes, etapas, máquinas, eficiência, qualidade e paradas
* Criação da view `vw_producao_detalhada`
* Criação e análise de índices com `EXPLAIN ANALYZE`
* Documentação das métricas e diagrama do schema

> Os dados do projeto são fictícios e foram criados para fins de estudo. Os indicadores representam análises sobre essa base simulada.
